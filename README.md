# Movies SPA

A Single Page Application for managing and discovering movies, built with vanilla JavaScript.

## 🚀 Features

- **User Authentication** - Register, login, and logout functionality
- **Movie Management** - Full CRUD operations (Create, Read, Update, Delete)
- **Like System** - Users can like movies (with duplicate prevention)
- **Authorization** - Owner-only edit/delete functionality
- **Hash-based Routing** - Smooth navigation without page reloads
- **Responsive Design** - Works on all devices

## 🛠️ Technologies

- Vanilla JavaScript (ES6+)
- HTML5 & CSS3
- REST API integration
- Session Storage for state management

## 📋 Prerequisites
